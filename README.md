# Imprenta-BackEnd

## Construccion del proyecto

1. Clonar el repositorio
```bash
git clone <URL_REPOSITORIO>
```

2. Entrar a la carpeta del backend
```bash
cd /IMPRENTA-BACKEND/backend/
```

3. Instalar dependecias
```bash
npm i
```

4. construir (carpeta dist)
```bash
npm run build
```

5. levantar la API
```bash
npm run dev
```
